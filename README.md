# ClassQuizServer — ESP32-S3-N16R8 课堂答题系统

基于 ESP32-S3-N16R8（16MB Flash + 8MB PSRAM）的局域网 HTTP 网络服务器。
学生手机/平板答题、教室大屏统计、教师后台管理三端合一，考试结果（分数/准确率）
自动保存在设备 Flash（LittleFS）中，断电不丢失。

## 一、快速开始

1. 用 USB 线连接 ESP32-S3 开发板。
2. 打开本文件夹（VS Code + PlatformIO 插件），先编辑 `ClassQuizServer/config.h`：
   - **接入教室路由器（推荐）**：填写 `STA_SSID` / `STA_PASS` 为教室 WiFi 名称和密码。
     学生、大屏电脑、教师电脑需连接同一 WiFi。注意：路由器需关闭"AP 隔离"。
   - **免路由器模式**：`STA_SSID` 留空即可，ESP32 自建热点
     `ClassQuiz`（密码 `12345678`），访问 `http://192.168.4.1`。
     （SoftAP 最多约 8 台设备同时在线，仅适合小规模演示）
3. 编译烧录：`pio run -t upload`，串口监视器：`pio device monitor`（115200）。
4. 串口中会打印 IP 地址（也可用 `http://classquiz.local`）。

## 二、三个访问入口

| 端 | 网址 | 使用设备 |
|---|---|---|
| 学生答题端 | `http://<IP>/` | 学生手机/平板（纯 HTTP，不显示题目） |
| 教室大屏统计端 | `http://<IP>/screen` | 教室大屏/投影电脑 |
| 教师工作台 | `http://<IP>/teacher` | 教师电脑或手机 |

## 三、使用流程

1. **教师工作台 → 班级栏**：新建班级（如"三年二班"）。
2. **教师工作台 → 题库栏**：输入试卷名，用 TXT 上传题目和答案（可上传 .txt 文件
   或直接粘贴内容）。TXT 格式：**题目一行、四个选项各占一行、再一行【答案】X**
   （X 为 A/B/C/D），多题连续排列。例：

   ```
   中国的首都是哪里？
   北京
   上海
   广州
   深圳
   【答案】A
   ```

   保存后试卷出现在大屏端的试卷选择框中。
3. **教师工作台 → 时间**：首次使用请设置设备时间（统计栏按日期归档依赖它；
   若 ESP32 能上网则自动 NTP 校时）。
4. **教室大屏端 → 首页**：
   - 底部两个选择框：班级选择框、试卷选择框；
   - 中间三个计分开关（单选）：
     - **一答计一**：每人只能提交一次答案；
     - **多答计一**：可多次提交，只有最后一次被记录统计；
     - **多答计多**：可多次提交，多次提交多次统计；
   - 点"下一页"进入第一题页面（整页题目与选项，右下角"下一页"）。
5. **答题**：学生手机打开学生端，点 A/B/C/D（顶部输入框自动更新所选答案），
   点"提交"。成功显示"已发送成功"，网络不通显示"发送失败"。
6. **提交统计页**：大屏顶部显示"第一题/第二题…"，正文"正在答题...已收到 N 份"，
   中间左为统计图框、中为答案框、右为准确率框；底部三个按键：
   - **返回首页**：终止本次考试，不归档；
   - **结束并统计**：统计图框显示 ABCD 人数柱状图（红/橙/绿/蓝），
     答案框显示本题答案，准确率框显示百分比；之后不再接收本题答案；
   - **下一题**：进入下一题页面，如此往复。
7. **考试结束页**：最后一题统计页点"下一题"即进入，页面中间显示"考试结束"。
   此时本次考试每题的答案分布与准确率自动**归档保存**到 Flash。
8. **教师工作台 → 统计栏**：按日期和班级筛选，查看每次考试的总体准确率，
   点"查看"可展开每题的答案、份数、准确率和 ABCD 分布。

## 四、项目文件

```
platformio.ini              构建配置（esp32-s3-devkitc-1, 16MB, OPI PSRAM）
partitions.csv              分区表（4MB 程序 + 约 12MB 数据存储）
ClassQuizServer/
  ClassQuizServer.ino       主程序（WiFi、HTTP 路由、考试状态机）
  config.h                  WiFi / 容量配置
  exam.h                    考试状态机（题库、提交记录、计分、统计）
  storage.h                 LittleFS 存储（班级 / 试卷 / 考试归档）
  util.h                    JSON 转义、名称清洗、时间工具
  pages_student.h           学生端页面
  pages_screen.h            教室大屏统计端页面
  pages_teacher.h           教师工作台页面
```

## 五、容量与限制

- 每份试卷最多 60 题（`MAX_QUESTIONS`，可改）
- 每题最多 1000 份提交记录（`MAX_SUBS`，可改；内存已验证充足）
- 归档记录存储空间约 12MB，可存数百场考试
- 学生以 IP 地址识别"每个人"；同一设备换不同网络出口会被视为不同人

## 六、常见问题

- **学生打不开页面**：确认与 ESP32 在同一网络；路由器模式下检查是否开启了
  "AP 隔离/客户端隔离"，需关闭。
- **统计栏日期为 1970**：设备未设置时间且无法 NTP 校时，请在教师工作台右上角
  设置时间。
- **忘了 IP**：看串口监视器启动日志，或试 `http://classquiz.local`。
- **上传烧录失败**：按住板上 BOOT 键再点上传。
